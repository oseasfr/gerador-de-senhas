## 🔐 Gerador de Senhas

Uma página web simples e funcional para:

- **Gerar senhas fortes** e seguras de forma personalizada  
- **Testar a força de senhas** que você já utiliza ou pretende usar

### ✅ Funcionalidades

- Escolha o tamanho da senha (de 10 a 20 caracteres)  
- Ative ou desative letras maiúsculas, minúsculas, números e símbolos  
- Copie a senha gerada com um clique  
- Veja se sua senha é fraca, média ou forte — com dicas para melhorar

### 🎨 Visual moderno

- Interface simples, bonita e responsiva  
- Imagens de fundo que mudam automaticamente  
- Funciona bem em celulares e computadores
